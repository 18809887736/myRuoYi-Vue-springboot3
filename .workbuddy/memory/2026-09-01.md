- 通读 myRuoYi-Vue-springboot3（RuoYi v3.9.2 / Spring Boot 3.5.14 / JDK 17），产出项目全貌总结给用户。
- 关键结论：
  - 标准版脚手架，尚无 VQMS/AVC 业务代码（无 HisCurveSvReader/Mysql57CurveReader/yx501 相关 Java），VQMS 属规划中待开发。

  - compose 关键点：SPRING_DATASOURCE_DRUID_MASTER_* / SPRING_DATA_REDIS_* 环境变量注入；TCP 探活（无 actuator）；nginx 用变量 proxy_pass + rewrite 剥 /prod-api 前缀 + docker DNS resolver 127.0.0.11。
  - 前端实际是 Vue 2.6.12 + element-ui 2.15.14 + vue-cli 4（README 的"Vue 3"说法不实），构建需 --openssl-legacy-provider。
